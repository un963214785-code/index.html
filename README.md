# NEU Creative Agency Template

## 📌 Overview

NEU is a clean and modern **HTML landing page template** designed with a soft **neumorphism UI style**. It is lightweight, minimal, and perfect for quickly creating a professional-looking website.

---

## ✨ Features

* Modern neumorphism design
* Clean and minimal layout
* Fully responsive (works on mobile & desktop)
* Built with Tailwind CSS
* Smooth animations and hover effects
* Easy to edit and customize

---

## 📦 What’s Included

* `index.html` (main template file)
* `documentation.txt` (setup and customization guide)
* `preview.jpg` (template preview image)

---

## 🚀 How to Use

1. Open `index.html` in any web browser
2. Edit text directly in the file using any code editor (VS Code recommended)
3. Change colors in the CSS `:root` section
4. Replace content with your own (name, services, etc.)
5. Save and deploy

---

## 🎯 Use Cases

* Creative agency websites
* Freelancer portfolios
* Startup landing pages
* Personal branding sites

---

## ⚠️ Important Notes

* This is a **front-end template only**
* Contact form is **not functional** (requires backend integration)

---

## 🛠️ Requirements

* A modern web browser
* Basic knowledge of HTML/CSS (for editing)
